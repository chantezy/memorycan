# 记忆罐头 Memory Can

把 Cursor、Trae、Claude 等 AI 对话记录保存在本地，随时搜索、回看与复盘。

记忆罐头是一款**本地优先**的 AI 对话记录管理工具：读取本机各类 AI 编程工具留下的会话数据，按项目归档，提供全文检索、时间线与可视化浏览。所有数据只留在你自己的电脑上，不上传任何服务器。

### 安装提示

- **macOS**：安装包未做代码签名与公证。首次打开若被系统拦截，请到「系统设置 → 隐私与安全性」点击「仍要打开」。
- **Windows**：安装包未签名。SmartScreen 提示时点击「更多信息 → 仍要运行」。

## 环境要求

- macOS 11 及以上（仅 Apple Silicon / arm64）
- Windows 10 及以上（x64）
